# Stop Condition · Rokhnama

Three conditions, not one — because the work never reaches the first condition. The second and third conditions are for saving the evening.

## Stop When
1. **All lines in `02-rubric.md` have been passed.** This is the success condition. The output is delivered.

**Or**

2. **Three consecutive rounds without meaningful change.** "Meaningful" means one rejected rubric line has been passed. If the same lines keep being rejected for three rounds, the issue is either the rubric lines are wrong or the work is poorly defined. The work stops and both possibilities are written.

**Or**

3. **90 minutes have elapsed.** Whatever is there is delivered, with a list of lines still pending rejection. The rest is homework for the next round.

---

## After Stop, Always
- One line in `06-decisions.md`: what decision was made and why
- If stopped by condition 2 or 3, the work proceeds to the blocked items file (with reason).
*Nothing is handed over without recording it.*

## What is NOT a Stop Condition
- "It looks good."
- "No better than this."
- "The user is probably satisfied."

None of these are rejectable, so none are stop conditions. If you catch yourself saying one of these, it means you didn't write the necessary rubric line.
