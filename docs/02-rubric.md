# Rubric · Rokhnama

Every line accepted or rejected. One rejection is sufficient. If a line is not rejected, it is not a line — write it or remove it. This file is written by a human and the model only executes; anything the model both writes and evaluates is no longer the standard.

## Text
1. No textual line in the UI (buttons, menus, errors) exceeds 90 characters. Button labels (CTAs and interactive buttons) must strictly not exceed 28 characters to prevent overflow and mobile layout breakage. Blog and landing page content are exempt.
2. The word "best" and any superlative adjective — "most suitable", "best" — must not appear anywhere.
3. Every string must use words from the "we say" column in `04-glossary.md` and must not contain any word from the "we don't say" column.

## Path and Experience
4. The crisis path is available in every page state — including errors, empty, loading, and offline states.
5. The empty state, phrase, or user selection repeats exactly in the text and proposes exactly one next step.
