# واژه‌نامهٔ محصول · رُخ‌نما

> این واژه‌نامه، زبان مشترک محصول رُخ‌نماست؛ نه یک واژه‌نامهٔ عمومی. ستون «نمی‌گوییم» به‌اندازهٔ ستون «می‌گوییم» اهمیت دارد.

---

## واژه‌های ممنوع

این واژه‌ها به‌صورت پیش‌فرض در هیچ رشته‌ای نمی‌آیند:

```text
انقلابی · بی‌نظیر · معجزه · فوق‌العاده · شگفت‌انگیز · فرصت طلایی
متحول‌کننده · بهترین · جامع‌ترین · پیشرفته‌ترین · ارزان‌ترین
بدون رقیب · تضمینی · هوشمندترین · بی‌رقیب · آنی
```

همچنین استفاده از واژهٔ «هوشمند» محدود به مواردی است که واقعاً قابلیت هوش مصنوعی در کار باشد، نه اتوماسیون ساده. 
از «هوش مصنوعی» نیز برای توصیف قابلیت‌های فعلی استفاده نمی‌کنیم، مگر اینکه همان قابلیت واقعاً در محصول وجود داشته باشد. وجود آن در Roadmap به معنی قابلیت فعلی نیست.

## واژگان خود کاربران

در منابع فعلی، مصاحبه یا نقل‌قول مستقیم از کاربران ارائه نشده است.

بنابراین نباید هیچ عبارت ساختگی را به‌عنوان «زبان واقعی کاربران» ثبت کنیم.

این بخش باید بعداً از موارد زیر تکمیل شود:

* مصاحبه‌های کاربری
* پیام‌های خریداران
* مکالمات تیم فروش
* تیکت‌های پشتیبانی
* عبارت‌های واقعی جست‌وجوی کاربران

عبارت‌های ثبت‌شده در این بخش باید عیناً حفظ شوند، حتی اگر در متن UI از معادل استاندارد محصول استفاده شود.

## اسم‌های داخلی

فقط در مستندات، تحلیل و کد استفاده می‌شوند و به کاربر نشان داده نمی‌شوند.

| اصطلاح                    | یعنی                           |
| ------------------------- | ------------------------------ |
| `page_view`               | بازدید صفحه                    |
| `product_view`            | مشاهدهٔ محصول                  |
| `product_modal_open`      | باز شدن جزئیات فنی محصول       |
| `first_click`             | اولین تعامل جلسه               |
| `share_link_open`         | باز شدن لینک اختصاصی           |
| `lifestyle_scenario_view` | مشاهدهٔ سناریوی کاربرد         |
| `qr_modal_view`           | تعامل ثبت‌شده از مسیر QR       |
| `contact_click`           | کلیک روی تماس یا استعلام       |
| `closed_to_open`          | بازگشت به کاتالوگ پس از خروج   |
| `COPY IN`                 | مرحلهٔ ورود و استخراج داده     |
| `RECORDS OUT`             | مرحلهٔ انتشار و خروجی داده     |
| `Hotspot`                 | نقطهٔ تعاملی روی محصول         |
| `PWA`                     | وب‌اپلیکیشن پیش‌رونده          |
| `CRM`                     | سیستم مدیریت ارتباط با مشتری   |
| `ERP`                     | سیستم برنامه‌ریزی منابع سازمان |
| `OTP`                     | کد یک‌بارمصرف پیامکی           |

## قاعدهٔ انتخاب واژه

اگر بین دو واژه مردد بودیم، واژه‌ای را انتخاب می‌کنیم که:

1. برای مخاطب B2B واضح‌تر باشد.
2. در نگاه اول قابل‌فهم باشد.
3. نیاز به توضیح اضافه نداشته باشد.
4. حرفه‌ای و کمی پرمیوم به نظر برسد.
5. بیشتر از قابلیت واقعی محصول وعده ندهد.

**رُخ‌نما قرار نیست پیچیده به نظر برسد؛ قرار است حرفه‌ای به نظر برسد.**
